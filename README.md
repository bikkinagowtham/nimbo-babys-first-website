# Nimbo — Baby’s First Website

A tiny interactive portfolio for haX.baby’s Baby’s First Website hackathon.

**Character:** Nimbo ☁️ — a tiny baby cloud in a yellow raincoat.

## Projects
- Rain Room
- Pocket Sunset
- Dream Forecast

## Interactions
- Day/night mode with localStorage
- Cursor-following Nimbo eyes
- Clickable clouds and stars
- Scroll-reveal story scenes
- Hidden Easter egg: click the moon five times

Built for a phone-first workflow.
